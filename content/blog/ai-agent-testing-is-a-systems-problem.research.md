# Research brief

## Thesis

Reliable AI agent assurance requires testing the agent as a system rather than evaluating generated text in isolation.

## Research questions

1. What components make an AI agent an observable system?
2. Which properties are deterministic and which require semantic judgment?
3. Why does orchestration behavior need separate evidence?
4. How should security testing relate to functional assurance?
5. What release-gating pattern avoids a misleading aggregate score?

## Source hierarchy

1. Primary vendor/platform documentation.
2. Standards and academic research.
3. Maintainer-authored engineering material.
4. Practitioner articles and community discussion for examples and counterpoints.

## Research status

This pilot article is intentionally conservative. It uses engineering reasoning and the Shyena assurance model as its primary argument rather than inventing market statistics. The production SAGE workflow will replace this manual research brief with a web-research artifact containing source URLs, publication dates, extracted evidence, and claim-to-source mappings.
