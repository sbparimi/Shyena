# Shyena

Automated AI Evaluation. Trusted Every Time.

Shyena is an end-to-end testing and AI evaluation platform for conversational AI
agents — chat and voice bots. It runs real, agent-driven conversations against your
live bot, judges the quality of every turn with LLM-based evaluation plus
deterministic checks, and gates every release so a broken conversation can never
report a false pass.
